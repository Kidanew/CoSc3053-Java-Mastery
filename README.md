**Haramaya University | College of Computing and Informatics | Department of Computer Science**

## 📌 Curriculum Overview

This comprehensive 90-day challenge curriculum bridges foundational Java syntax to production-grade enterprise microservices, Spring Boot, multithreading, and distributed systems architecture.

### 🗓️ Phase Roadmap Summary

| Phase | Days | Primary Focus & Competencies | Key Deliverable / Milestone |
| :--- | :--- | :--- | :--- |
| **Phase 1: Foundations** | 1–18 | Java Execution Model, Primitives, Arrays, Strings, OOP, Collections, Streams, Modern Java | **Milestone 1 (Day 18)**: Console Library System (`m1`) |
| **Phase 2: I/O Streams** | 19–24 | File System, NIO.2, Byte Streams, Character Streams, Object Serialization, CSV Engine | File Audit & Persistence Engine |
| **Phase 3: JavaFX GUI** | 25–38 | Stage/Scene Graph, Layout Panes, Event Model, TableView, Properties, FXML, CSS, Tasks | **Milestone 2 (Day 33)**: Desktop Student Manager GUI (`m2`) |
| **Phase 4: JDBC & Persistence** | 39–48 | RDBMS, SQL, JDBC Architecture, PreparedStatement, DAO Pattern, Transactions, Batching | **Milestone 3 (Day 48)**: Database Student Records System (`m3`) |
| **Phase 5: Networking (TCP/UDP)** | 49–58 | Sockets, TCP Echo & Multithreaded Servers, UDP Discovery, Application Protocols | **Milestone 4 (Day 58)**: Networked Student Lookup System (`m4`) |
| **Phase 6: Multithreading** | 59–68 | Thread Life Cycle, Synchronization, Locking, Executors, Virtual Threads (Loom), Deadlocks | **Milestone 5 (Day 68)**: Concurrent Ticket Booking Engine (`m5`) |
| **Phase 7: RMI & Distributed Systems** | 69–73 | RMI Architecture, Remote Interfaces, RMI Callbacks, Distributed Data Services | Distributed RMI Student Service (`rmi-lab`) |
| **Phase 8: Servlets, Web & Spring Boot**| 74–81 | HTTP Protocol, Servlets, Spring Web, Sessions, MVC, Spring Data JPA, REST APIs | **Milestone 6 (Day 81)**: Enterprise Web Student Portal (`m6`) |
| **Phase 9: Integrated Capstone** | 82–90 | End-to-End Microservice / Desktop System, Security Audit, Testing, JAR Packaging, Demo | **Final Capstone (Day 90)**: Live System Demo & Defense (`final`) |

## 🚀 Student Self-Study Workflow & Submission Rules

1. **Daily Cadence**: Spend 30–90 minutes per day working on the assigned daily sheet.
2. **4-Layer TODO Structure**: Complete each `// TODO` block sequentially following the 🎯 **Concept & Goal**, 📋 **Validation Rules**, 💡 **Step-by-Step Hints**, and 🧪 **Expected Test Case**.
3. **Verification**: Confirm your output matches the **Expected Output** section and run the automated test checks.
4. **Git Version Control**: Commit your code daily (`git commit -m "feat(dayXX): complete challenge"`) to build a clean portfolio log.
